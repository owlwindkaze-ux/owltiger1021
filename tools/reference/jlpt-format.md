## 3　聴解の答え方の流れ（公式）

音を作るとき・原稿を読むときは、この順番を守ります。

| 形式 | 流れ | 選択肢 |
|---|---|---|
| **課題理解** | 説明と質問を聞く → 話を聞く → **もう一度質問を聞く** → 答えを選ぶ | 問題用紙に印刷（4択） |
| **ポイント理解** | 説明と質問を聞く → **ポーズの間に選択肢を読む** → 話を聞く → もう一度質問を聞く → 答えを選ぶ | 問題用紙に印刷（4択） |
| **概要理解** | 説明を聞く → 話を聞く → **質問と選択肢を聞く**（紙には何も印刷されていない） → 答えを選ぶ | 印刷なし・耳で聞く（4択）**← 画面でも再現ずみ** |
| **発話表現**（N3まで） | **絵を見ながら**質問を聞く → 矢印（→）の人が何と言うかを選ぶ | 3択 |
| **即時応答** | 短い発話を聞く → すぐに応答を選ぶ | 3択 |
| **統合理解**（N2から） | 長めの話を聞く。**質問が2つある形**もある | 形により異なる |

- **メモを取りながら聞いてよい**（公式に明記）。
- 「ポーズ」＝何も聞こえない時間。ポイント理解では、ここで選択肢を読ませます。

> **いまの教材との違い（意図的）**：発話表現は公式では**絵**を見て答えますが、
> この教材では**場面を言葉で説明する**形にしています。紙とスマホで絵を用意するのが
> 難しいためです。場面の説明を1文で簡潔にすることで、同じ力を測るようにしています。

## 5　作るときに守ること（この教材の方針）

- **公式の問題例は写さない。** 形式だけを借りて、中身は介護の現場でオリジナルに書く。
- **出題範囲は教えた範囲から出す。** 判定テストは `tools/hani/n4hantei-check.py` が機械で確かめる。
- **正解の番号をかたよらせない。** 選択肢の並べかえだけで直す（文と正解は変えない）。
  順番に意味のある選択肢（一つ・二つ／一時・二時／曜日）は並べかえない。
- **本文の長さは上の表の幅に収める。**
