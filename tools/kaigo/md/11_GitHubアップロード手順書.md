# GitHub Pages アップロード手順書

**用途：Claudeで作った教材ファイル（HTML）を、自分のサイトに置いて実習生に使ってもらう**
**対象サイト：owlwindkaze-ux.github.io/owltiger1021/**
**作成日：2026年8月18日**

## はじめに｜3つの前提

**1．Claudeは自分でGitHubにアップロードできません**
Claudeはファイルを作ることはできますが、あなたのGitHubアカウントに入る手段を持っていません。
アップロードは毎回ご自身の作業になります。勝手にサイトが書きかわることはありません。

**2．公開元は main ブランチです**
2026年8月に、作業用ブランチ（claude/japanese-n3-kanji-AaKYe）から main へ移行しました。
main は最初から表示されているブランチなので、**通常はブランチを切りかえる必要はありません。**
念のため、ファイル一覧に bunpo と choukai のフォルダが見えることだけ確認してください。

**3．Chromeの自動翻訳がかかっています**
GitHubの画面が日本語に翻訳されているため、フォルダ名やボタン名まで日本語に変わって表示されます。
実際のファイル名は英語のままなので、心配いりません。下の対応表を見てください。

### 画面の日本語と、本当の名前

| 画面の表示 | 本当の名前・意味 |
|---|---|
| 支店 | Branches（ブランチ） |
| 主要 | main（ブランチの名前） |
| 行動 | Actions（公開処理の記録） |
| 問題 | Issues |
| 文法 | bunpo（フォルダ名） |
| チョウカイ | choukai（フォルダ名） |
| ドッカイ | dokkai（フォルダ名） |
| .クロード | .claude（フォルダ名） |
| 変更をコミットします… | Commit changes（保存して反映する） |

翻訳を止めたい場合：アドレスバーの右端にある翻訳アイコン（四角が2つ重なった形）をクリックし、
「英語のまま表示」を選びます。慣れてきたら、そのほうが迷いません。

## 手順｜全8ステップ

### ステップ1　ファイルをダウンロードする

Claudeとの会話画面で、ファイルのカード（例：介護の日本語 聴解練習）をクリックします。
パソコンの「ダウンロード」フォルダに保存されます。

### ステップ2　メモ帳で開く

ダウンロードしたファイルを **ダブルクリックしないでください。**
ダブルクリックするとブラウザで開いてしまい、完成した画面が表示されるだけでコピーできません。

・ファイルを **右クリック**
・「プログラムから開く」
・「メモ帳」を選ぶ（一覧になければ「別のプログラムを選択」から探す）

<!DOCTYPE html> から始まる、記号だらけの長い文章が出てきます。**これが中身です。**

### ステップ3　全部コピーする

メモ帳の画面で、
・**Ctrl + A**（全部を選ぶ）
・**Ctrl + C**（コピーする）

メモ帳はそのまま開いておいて構いません。

### ステップ4　GitHubを開いて、ブランチを確認する

1. ブラウザで github.com/owlwindkaze-ux/owltiger1021 を開く
1. 上のタブのいちばん左「**コード**」をクリック
1. ファイル一覧の左上のボタンが「**main**（または「主要」）」になっていることを確認する

**確認：** ファイル一覧に「文法（bunpo）」「チョウカイ（choukai）」のフォルダが見えていれば正解です。
main は初期表示のブランチなので、通常は何も操作しなくてこの状態になっています。

### ステップ5　新しいファイルを作る

1. 緑の「コード」ボタンの左にある「**ファイルを追加**」をクリック
1. 「**新しいファイルを作成**」を選ぶ（「ファイルをアップロード」ではありません）

### ステップ6　ファイル名を入れる

画面上部の入力欄に、**半角**で次のように入力します。

choukai2/index.html

・choukai2 の部分が、あなたが決めるフォルダ名です（次の教材なら choukai3 など）
・**スラッシュ（/）を入れると、GitHubが自動でフォルダを作ってくれます**
・後半の index.html は毎回このままです。変えないでください

入力すると画面上部に「owltiger1021 / チョウカイ2 /」のようにカタカナで表示されますが、
これは翻訳されているだけです。実際は choukai2 になっています。

### ステップ7　貼り付けてコミットする

1. 中央の「Enter file contents here」と書かれた枠の中をクリック
1. **Ctrl + V** で貼り付ける
1. 右上の緑の「**変更をコミットします…**」を押す
1. 確認画面が出たら、メッセージ欄は空のままで、もう一度コミットのボタンを押す

**貼り付けの確認：**
・1行目が <!DOCTYPE html> になっている
・いちばん下の行が </html> になっている

この2つが揃っていれば、全部貼れています。行数は気にしなくて構いません
（聴解ウィジェットは524行です）。

### ステップ8　開いて確認する

2〜3分待ってから、ブラウザのアドレスバーに次を入力して Enter を押します。

https://owlwindkaze-ux.github.io/owltiger1021/choukai2/

choukai2 の部分は、ステップ6で決めたフォルダ名に合わせてください。

**404 と出た場合**：まだ公開処理が終わっていないだけのことが多いです。3分待って **F5**（再読み込み）。
それでも出ないときは、GitHubの「**行動（Actions）**」タブを開くと、処理が成功したか失敗したかが分かります。
緑のチェックが付いていれば完了です。

## つまずきやすい点｜Q&A

**Q　「コード画面」とはどこですか。**
A　リポジトリ名の下に並ぶタブの、いちばん左「コード」です。ファイル一覧が表示される画面のことです。
設定タブを開いているときは、左端の「コード」をクリックすれば戻れます。

**Q　「メモ帳でコピーしたHTML」とは何ですか。**
A　ダウンロードしたHTMLファイルを、ブラウザではなくメモ帳で開いたときに表示される、
タグだらけの長い文章のことです。ブラウザで開いた「見た目のきれいな画面」ではありません。

**Q　行番号が2000行もありません。**
A　問題ありません。聴解ウィジェットは524行です。大事なのは行数ではなく、
最後が </html> で終わっているかどうかです。

**Q　フォルダ名が「チョウカイ」とカタカナで表示されます。間違えましたか。**
A　間違えていません。Chromeの自動翻訳です。実際のフォルダ名は choukai になっています。

**Q　URLはブラウザで開くのですか。**
A　はい。Chromeの一番上のアドレスバー（github.com/... と表示されている横長の欄）に
URLを入力して Enter を押します。

**Q　Claudeが勝手にGitHubを操作することはありますか。**
A　ありません。Claudeはあなたのアカウントに入る手段を持っていません。
ファイルを作るところまでが Claude、アップロードはご自身、という分担です。

**Q　同じフォルダ名で上書きしたいときは。**
A　既存の index.html をクリックして開き、右上の鉛筆マーク（編集）を押します。
Ctrl + A で古い中身を全部消してから、新しい中身を Ctrl + V で貼り付け、コミットします。
