２．各問題は 2回 読みます。1回目と2回目のあいだは 5秒 あけてください。

# **【解答・解説】**

## **問題1　申し送りを聞く**

| **問** | **答** | **解説** |
|---|---|---|
| **(1)** | **2** | **「おなかが痛いと言われました」。訴え＝利用者さんが伝えるからだのつらさ。／ Uttae = keluhan penghuni.** |
| **(2)** | **3** | **「便は3日出ていません」。3日以上で便秘を疑い、看護師に報告する。／ Tidak BAB 3 hari → lapor ke perawat.** |
| **(3)** | **2** | **「朝食は半分残されました」。食事量は「全量・2分の1・少量」で記録する。／ Dicatat: seluruhnya / setengah / sedikit.** |
| **(4)** | **2** | **「今日の午後、リハビリのあとで」。運動後は疲れや血圧低下でふらつきやすい。／ Setelah rehabilitasi mudah limbung.** |
| **(5)** | **2** | **「必ず付きそってください」。付きそう＝そばにいて安全を守る。／ Tsukisou = mendampingi penghuni.** |
| **(6)** | **3** | **「明日の午前中に、ご家族の面会があります」。予定は申し送りで必ず伝える。／ Jadwal selalu disampaikan.** |

## **問題2　声かけを聞く**

| **問** | **答** | **解説** |
|---|---|---|
| **(1)** | **〇** | **介助の前に説明し、同意を得ている。「説明と同意」の基本。** |
| **(2)** | **×** | **職員の都合を優先した命令口調。急がせると誤嚥の危険。→「ゆっくり召し上がってくださいね」** |
| **(3)** | **×** | **排泄のことを大きな声で言うと、はずかしい思いをさせる。→小さな声で「おむつを交換させていただきますね」** |
| **(4)** | **〇** | **部屋に入るときの基本。ノックをして、返事を待ってから入る。** |
| **(5)** | **〇** | **できることはご自分でしていただく「自立支援」の声かけ。** |
| **(6)** | **×** | **禁止だけの声かけは意欲を下げる。→「お手伝いしますので、立つときは呼んでくださいね」** |

**採点のとき：**×を選べていても、理由が言えない実習生がいます。答え合わせのときに「なぜ よくないのですか」と1問ずつ聞いてください。ここが本当の理解です。

## **問題3　利用者さんの ことばを聞く**

| **問** | **答** | **解説** |
|---|---|---|
| **(1)** | **2** | **胸の苦しさは心疾患のサインのことがある。自分で判断せず、すぐ看護師へ。／ Segera lapor ke perawat.** |
| **(2)** | **2** | **水分の訴え。脱水予防のためこまめにすすめる。とろみの要否は事前に確認。／ Cegah dehidrasi.** |
| **(3)** | **3** | **排泄は我慢させない。すぐ付きそって誘導する。一人にすると転倒の危険。／ Jangan tinggalkan sendirian.** |
| **(4)** | **2** | **痛みはまず確認と報告。職員の判断で薬や湿布は使えない。無理に歩かせない。／ Staf tidak boleh memberi obat.** |
| **(5)** | **3** | **認知症のある方への対応。否定せず、笑顔で自己紹介し、安心できる声かけを。／ Jangan menyangkal.** |

## **問題4　書き取り**

| **問** | **答** | **部分点** |
|---|---|---|
| **(1)** | **体温は 36度8分です。** | **数字が合っていれば1点。漢字はひらがなでも可。** |
| **(2)** | **転倒は していません。** | **「していません」（否定）が書けていれば1点。** |
| **(3)** | **水分を すすめてください。** | **「水分」が書けていれば1点。** |

**書き取りの採点方針：**漢字のまちがいは減点しません。ひらがなでも構いません。見るのは、数字と否定形が正しく聞き取れているかの2点です。「36度8分」を「38度6分」と書く、「していません」を「しています」と書く——この2種類のまちがいは、現場では事故につながります。ここだけは厳しく見てください。
