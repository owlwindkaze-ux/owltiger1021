# 第1回　報告の型をおぼえる

## 報告の5つの部分

介護の報告は、いつも この順番です。順番を 変えると、聞く人が 混乱します。

|  | 部分 | 例 |
|---|---|---|
| ① | 切り出し | 鈴木さん、報告が あります。今、よろしいでしょうか。 |
| ② | いつ・どこで | 午前10時ごろ、廊下で |
| ③ | だれが・どうなったか | 高橋さんが ふらつかれました |
| ④ | 自分が したこと | すぐに そばへ 行き、いすに 座って いただきました |
| ⑤ | 今の様子 | 今は 落ち着いて いて、けがは ありません |

# 第2回　「見たこと」と「思ったこと」を 分ける

## なぜ 分けるのか

報告には **事実（見たこと・聞いたこと）** と **推測（自分が 思ったこと）** が まざります。
まざったまま 報告すると、先輩は どちらか 分からず、判断を まちがえます。

・×「たぶん めまいだと 思います。ふらついていました。」　← 推測が 先
・○「ふらついて おられました。めまいが あるのかも しれません。」　← 事実が 先、推測は あとで 分けて

**インドネシア語**：Pisahkan **fakta** (yang Anda lihat/dengar) dari **dugaan** (pendapat Anda). Fakta dulu, baru dugaan.

## 練習1　事実か 推測か（各1点・10点）

次の 文が **事実** なら「事」、**推測** なら「推」と 書きなさい。

1. 顔色（かおいろ）が 白（しろ）かったです。（　　）
1. たぶん 熱が あると 思います。（　　）
1. 体温は 37度8分でした。（　　）
1. 昨日より 元気が ないようです。（　　）
1. 朝食を 半分 残されました。（　　）
1. 食欲（しょくよく）が 落（お）ちているのかも しれません。（　　）
1. 「おなかが 痛い」と 言われました。（　　）
1. 便が 3日 出ていません。（　　）
1. 便秘だと 思います。（　　）
1. 右足を 引（ひ）きずって 歩いて おられました。（　　）

# 第4回　介護記録を 書く

## 記録の3つの きまり

1. **事実だけ 書く**（推測は「〜と思われる」と 分けて 書く）
1. **具体的に 書く**（「たくさん」「少し」ではなく、数字や 決められた ことばで）
1. **その日の うちに 書く**（あとで 書くと まちがえます）

### 使う ことば

| 項目 | 書き方 |
|---|---|
| 食事量 | 全量／2分の1／3分の1／少量／摂取（せっしゅ）なし |
| 水分量 | 150ml、200ml のように 数字で |
| 排泄 | 排尿（はいにょう）○回、排便（はいべん）○回、性状（せいじょう）：普通便・軟便（なんべん）・硬便（こうべん） |
| 入浴 | 入浴実施／清拭（せいしき）に 変更（へんこう）／中止 |
| バイタル | 体温 36.5℃、血圧 130／80、脈拍 72 |

**インドネシア語**：Catatan harus **faktual**, **spesifik dengan angka**, dan ditulis **pada hari yang sama**.

# 第5回　ヒヤリハット報告書を 書く

## ヒヤリハットとは

事故には ならなかったが、「ヒヤリ」と した、「ハッ」と した できごとの ことです。
**事故ではないから 書かなくていい、ではありません。** 事故を 防（ふせ）ぐために 書きます。
**書いた人が しかられる ことは ありません。** 隠（かく）す ことが いちばん よくありません。

**インドネシア語**：Laporan hiyari-hatto = kejadian nyaris celaka. Ditulis untuk **mencegah** kecelakaan, bukan untuk menyalahkan siapa pun. Jangan pernah menyembunyikannya.

## 様式（ようしき）

| 項目 | 書くこと |
|---|---|
| 発生日時（はっせいにちじ） | ○月○日 ○時○分ごろ |
| 発生場所 | 居室・廊下・浴室・食堂 など |
| 対象者（たいしょうしゃ） | ○○様 |
| 発生状況（じょうきょう） | 何が あったか（事実だけ） |
| とった対応（たいおう） | 自分が 何を したか |
| その後の様子 | けがの 有無（うむ）、今の 状態 |
| 考えられる原因 | なぜ 起きたか（推測でよい） |
| 再発防止（さいはつぼうし） | 次から どうするか |

# ここから下は 職員用です

**実習生に渡す問題用紙は、この行の前までを 印刷してください。**この下には 解答（と、教材によっては 読み上げ用スクリプト）が 入っています。

## 全5回を 終えたら

・第5回の 練習1・2が 自分で 埋（う）められるように なったら、実際の 施設様式（ようしき）に
差しかえて、同じ形で 練習させてください。様式が変わっても、書く中身は 同じです。
・記述が 安定した実習生は、N3版の 問題8（自由記述）に そのまま 対応できます。
・逆に、ここで つまずく 場合は、第2回（事実と推測）に 戻（もど）るのが 近道です。
記述が 書けない 原因の ほとんどは、日本語では なく **事実と推測が 分けられていない** ことです。

## 解答

### 第1回　報告の型をおぼえる


**練習1**　ウ → イ → オ → エ → ア

**練習2 採点基準**（①〜⑤ 各2点）
・(1) 解答例：
> 鈴木さん、報告が あります。今、よろしいでしょうか。
> 午前7時ごろ、居室で 山田さんが ベッドから 降りようとして、ふらつかれました。
> 転倒は していません。すぐに そばへ 行って、ベッドに 座って いただきました。
> 今は 落ち着いて おられます。
・(2) 解答例：
> 鈴木さん、報告が あります。
> 午後4時ごろ、浴室の 前で 田中さんが 「めまいが する」と 言われました。
> すぐに いすに 座って いただき、看護師を 呼びました。
> 今日の 入浴は 中止に なりました。

**指導ポイント**：この回では、⑤（今の様子）を 落とす実習生が いちばん多いです。
報告を 受けた 先輩が 「それで、今は？」と 聞き返す 報告は、現場では 役に立ちません。

### 第2回　「見たこと」と「思ったこと」を 分ける


**練習1**　1 事／2 推／3 事／4 推／5 事／6 推／7 事／8 事／9 推／10 事

**練習2 解答例**
・(1)
> せきを して おられました。体温は 37度5分でした。
> 風邪の 可能性（かのうせい）が あるかも しれません。
・(2)
> あまり 話されず、食事も 少ししか 召し上がりませんでした。
> いつもより 元気が ないように 見えました。

**採点**：事実を すべて 先に 書けている（3点）／推測を 最後に 分けて 書けている（2点）。
推測を 完全に 消（け）した 解答も 正解と します。**推測は 書かなくても よい**が、
書く なら 最後に 分ける、というのが ルールです。

**指導ポイント**：「〜と思います」「〜ようです」「〜かもしれません」が 出てきたら 推測です。
この3つを 赤ペンで 囲（かこ）ませると、自分で 見分けられるように なります。

### 第3回　時間の 順番に 書く


**練習1 解答例**
・(1) 声を かけましたが、返事が ありませんでしたので、肩を 軽く たたきました。
・(2) 食堂へ お連れして、車いすの ブレーキを かけてから、お食事を お出ししました。

**練習2 採点基準**（各3点）
| 観点 | 見るところ |
|---|---|

### 第5回　ヒヤリハット報告書を 書く


**練習1 記入例**（各項目2〜3点）

**練習2 記入例**

| 項目 | 記入例 |
|---|---|
| 発生日時 | 9月10日 11時40分ごろ |
| 発生場所 | 食堂 |
| 対象者 | 佐藤様 |
| 発生状況 | お出しした お茶が 熱く、「熱い」と 言われ、口を 押さえられた |
| とった対応 | すぐに 冷水を お出しし、口腔（こうくう）内を 確認。看護師に 報告し、確認して いただいた |
| その後の様子 | 発赤（ほっせき）・やけどなし |
| 考えられる原因 | お出しする前に 湯（ゆ）の 温度を 確認していなかった |
| 再発防止 | 提供前に 温度を 確認する。熱い場合は 少し さましてから お出しする |

**練習3 解答例**
> 鈴木さん、ヒヤリハットの 報告が あります。
> 先ほど 305号室で、山田様の 移乗の とき、車いすの ブレーキを かけ忘れて いました。
> すぐに 支えましたので、転倒も けがも ありません。報告書を 書いて 提出（ていしゅつ）します。

**採点**（各項目の配点は表のとおり／練習3は 結論が先＝4点、事実＝3点、その後の対応＝3点）

**指導ポイント**
・「考えられる原因」に **「自分が悪かった」「気をつけていなかった」** と 書く 実習生が 多いです。
これは 原因では なく 反省（はんせい）です。**行動** で 書かせてください（例：「確認をしていなかった」）。
・「再発防止」も 「気をつけます」では 意味が ありません。
**次から 何を するか**（例：「声に出して確認する」）を 書かせます。
・ここが 書けるように なれば、日本語の 力だけで なく、**安全を 考える力** が ついています。
