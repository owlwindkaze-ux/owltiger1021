# Belajar Bahasa Jepang Kaigo ／ 介護の日本語学習システム

介護施設で働くインドネシア人技能実習生のための、**JLPT N5〜N2** 対応・無料の日本語学習システムです。
漢字・語彙・文型（文法）・読解・聴解の5技能に加えて、**試験日から逆算した学習コース**（N3合格100日コース／新人コース／N2コース）を備えています。

Sistem belajar bahasa Jepang gratis untuk pemagang asal Indonesia yang bekerja di panti jompo (kaigo), level **JLPT N5–N2**.
Mencakup kanji, kosakata, tata bahasa, membaca, dan menyimak — plus program belajar terjadwal mundur dari tanggal ujian.

**▶ 公開URL / Link:** https://owlwindkaze-ux.github.io/owltiger1021/
**▶ 合言葉 / Kata sandi:** `owltiger2026`

## 使い方 ／ Cara pakai

URLを開くだけです。インストール不要、スマホ・パソコン両対応。
Cukup buka link di atas. Tanpa instalasi, bisa di HP maupun komputer.

入口メニューから、次の**10システム**を選べます。詳しい使い方はすべて [MANUAL.md](MANUAL.md) にあります。

| システム | 内容 |
|---|---|
| 漢字・語彙（`kanji.html`） | 漢字1,144字・語彙6,659語。下表参照 |
| 文型・文法（`bunpo/`） | 466文型。「〜てもいいです」など、話すときの文の形 |
| 読解（`dokkai/`） | 80本・設問224問。お知らせ・シフト表・体験談などを読んで答える |
| 聴解（`choukai/`） | 143問。申し送り・会話・利用者さんの言葉を聞いて答える（端末の音声合成を使用） |
| **まちがえたところ**（`fukushu/`） | 漢字・語彙・文型・読解・聴解・100日・模試の**7区分を横断**して、まちがえた問題だけを1画面に集める |
| **N3合格100日コース**（`n3.html`） | 試験日から逆算した週ごとの学習（第1〜14週・1,226問）。再受験・期限つきの人向け |

| 手書き検索（`tegaki.html`） | 読めない漢字を枠に書いて調べる（収録6,412字）。覚えるためでなく、その場で引く道具 |

### 漢字・語彙タブの内訳（`kanji.html`）

| タブ | Tab | できること |
|---|---|---|
| 漢字一覧 | Kanji | 1,144字をカード表示。検索（漢字・読み・意味・用例）、レベル/画数/頻度で並べ替え。カードをタップで詳細 |
| 語彙 | Kosakata | 6,659語（JLPT語彙＋**介護566語**＋現場125語＋記録757語）。レベル・分野・**形**（熟語／動詞／かな語／カタカナ語／語形成）で絞り込み、タップで構成漢字の書き順へ |
| フラッシュカード | Kartu | 「漢字→読み」「漢字→意味」「読み→漢字」「意味→漢字」の4モード。覚えた／要復習で仕分け |
| 練習問題 | Latihan | JLPT本試験と同じ5〜6形式の4択問題（下記「品質について」参照） |
| 書き順 | Urutan Coretan | 1画ずつの連続図（新しい画は赤）。文字をタップすると1画ずつアニメーションで書きます |
| 学習状況 | Progres | レベル別の到達率、要復習リスト、記録の書き出し |

### 詳細画面（カードをタップ）
- 開くと **自動で1画ずつ書き順アニメーション**が再生されます（もう一度見るには文字か「再生」をタップ）
- 音読み・訓読み、意味（インドネシア語＋英語）、用例（ふりがな・JLPTレベル付き）、部首

### キーボード操作（パソコン、フラッシュカード）
`Space`/`Enter` 答えを見る ・ `→`/`←` 次/前 ・ `1` まだ ・ `2` 覚えた ・ `Esc` 閉じる

### 学習記録
記録はブラウザ（端末内 localStorage）にのみ保存されます。サーバーには送信されません。
Catatan belajar hanya disimpan di perangkat Anda, tidak dikirim ke server.

### ローカルで動かす場合

### 漢字を追加・修正するには
`kanji-data.json` の `kanji` 配列を編集し、**そのあと `python3 tools/split-data.py` を走らせます**（1字ぶんの形）：
```json
{
  "character": "新", "level": "N4", "strokes": 13,
  "on": ["しん"], "kun": ["あたら.しい", "あら.た"],
  "meanings": ["new"], "meanings_id": ["baru"],
  "radical": {"character": "斤", "name": "おのづくり", "meaning": "axe"},
  "examples": [{"word": "新聞", "reading": "しんぶん", "meaning": "newspaper",
                "meaning_id": "surat kabar", "jlpt": "N5"}]
}
```
書き順も追加する場合は `kanji-strokes.json` の `strokes` に、その漢字の SVG パスを筆順どおりの配列で追加します（KanjiVG から取得可）。

## 品質について ／ Kualitas data

**N5〜N3の初期612字（現在の土台部分）について、公開当時に行った検証：**

- 画数は **KANJIDIC2・Kanji alive・KanjiVG の3つの独立したデータで完全一致**を確認済み（612字すべて、不一致0件）
- 全612字に読み・意味・用例（平均3.98語）・筆順データが揃っていることを自動検証済み
- ブラウザ実機テスト（Chromium）**83項目に合格**：合言葉ゲート・表示・検索・絞り込み・アニメーション・言語切替・記録保存・スマホ表示・JSエラーなし
- インドネシア語訳は、漢字・読み・用例の**日本語の文脈ごと**に作成（英語だけを見て訳すと「権利→kanan（右）」のような同形異義語の誤訳が起きるため）
- 独立した第三者レビューで **175字・866文字列を抽出検査 → 正確度 約99.3%、重大な誤り0件**。指摘された箇所は修正済み

**それ以降に追加した分（N2・介護・記録・語彙6,659語・文型466・読解80本・聴解143問など）について：**

- 上記と同じ3ソース照合・第三者抽出検査は行っていません。追加のたびに個別の「点検」（機械検査＋目視確認）を行っており、内容は `SPEC.md` の開発ログ（日付つきの節）に記録されています
- 練習問題（例文・4択問題）は生成時に機械検査を実施：見出し語が文中に含まれるか・重複がないか・選択肢が4つで正解が過不足なく含まれるか、などを自動検証
- 誤訳・誤りを見つけた場合は `kanji-data.json` / `vocab-data.json` の該当箇所（`meanings_id` / `meaning_id`）を修正し、`python3 tools/split-data.py` を走らせてください
